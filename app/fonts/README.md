# Bundled typefaces

Inter (variable weight 100–900) and Newsreader (variable weight 200–800) are the existing Google Fonts Latin WOFF2 assets, now served through next/font/local so builds do not need a font download. The original files were copied unchanged from this project's development asset cache; their family names and weight ranges were verified using Next.js's bundled font metadata reader.

Both fonts use the SIL Open Font License 1.1; copyright notices and full licenses are adjacent. Sources: https://github.com/google/fonts/tree/main/ofl/inter and https://github.com/google/fonts/tree/main/ofl/newsreader. Characters outside these Latin subsets use the font fallback.
