# Cornerstone Finance

A financial-literacy and portfolio-research website for emerging investors.

Start with [PROJECT.md](PROJECT.md) for purpose, architecture, commands, design boundaries and the multi-session context system.

- [Area map](docs/project/AREAS.md)
- [Current state and gaps](docs/project/STATUS.md)
- [Work-session and handoff guide](docs/project/WORKFLOW.md)
- [Security requirements](SECURITY.md)
- [Private beta gates](BETA.md)

The local npm app is Next.js. Root HTML/JavaScript/CSS files preserve the older static implementation; do not confuse the two or delete the legacy version without an explicit migration decision.

From the repository root, use `npm run dev` to work locally. See PROJECT.md before changing dependencies, data integrations or deployment.
